Using these resistance values, the approximate operating point of the transistor can be calculated.  
Since the base current \(\Ix{B}\) is much smaller than the current through \(R_2\), the base voltage is approximated as shown in Equation~\ref{eq:VBcalc}.  

\begin{equation}
    \label{eq:VBcalc}
    \Vx{B} \approx \Vx{CC} \cdot \frac{R_2}{R_1 + R_2}
\end{equation}

The emitter voltage is then given by Equation~\ref{eq:VEcalc}, assuming a base-emitter drop of \(\qty{0.7}{\volt}\).  

\begin{equation}
    \label{eq:VEcalc}
    \Vx{E} = \Vx{B} - \Vx{BE}
\end{equation}

The emitter current is determined from Ohm's law according to Equation~\ref{eq:IEcalc}.  

\begin{equation}
    \label{eq:IEcalc}
    \Ix{E} = \frac{\Vx{E}}{\Rx{E}}
\end{equation}

As \(\Ix{C} \gg \Ix{B}\), the collector current is approximated as equal to the emitter current.  
The collector voltage is therefore given by Equation~\ref{eq:VCcalc}.  

\begin{equation}
    \label{eq:VCcalc}
    \Vx{C} = \Vx{CC} - (\Ix{C} \cdot \Rx{C})
\end{equation}

Finally, the intrinsic emitter resistance \(\rx{e}\) is calculated using Equation~\ref{eq:recalc}, which is provided in the assignment as Eq.~3.1.  

\begin{equation}
    \label{eq:recalc}
    \rx{e} = \frac{\qty{25}{\milli\volt}}{\Ix{E}}
\end{equation}

To compare measured and theoretical results, the relative difference is calculated using Equation~\ref{eq:diff}.
In this expression, \(M\) denotes the measured value and \(C\) denotes the calculated (theoretical) value.
The difference is expressed as a percentage of the calculated value.

\begin{equation}
    \label{eq:diff}
    \text{Difference (}\unit{\percent}\text{)} =
    \frac{M - C}{C} \cdot 100
\end{equation}

For this part of the experiment, only the intrinsic emitter resistance \(\rx{e}\) was compared.  
The measured value of \(\rx{e}\) differed from the calculated value by \(\qty{2.99}{\percent}\).

\subsection{Voltage Gain}
% #region

The voltage gain of the amplifier can be estimated theoretically using the intrinsic emitter resistance.  
According to the assignment, the expression for \(\Ax{V}\) is given in Equation~\ref{eq:AVcalc}, which is referred to as Eq.~3.2.  

\begin{equation}
    \label{eq:AVcalc}
    \Ax{V} = - \frac{\Rx{C}}{\rx{e}}
\end{equation}

The input signal specified in the assignment is \(\Vx{sig} = \qty{20}{\milli\volt}\).  
However, this value resulted in a distorted output, so the signal generator was set to \(\qty{14}{\milli\volt}\) to avoid distortion.  

The output amplitude \(\Vx{o}\) was measured and the experimental voltage gain was calculated using Equation~\ref{eq:AVdef}.  
This expression follows directly from the definition of voltage gain as the ratio of output to input.  
The negative sign indicates the \(\ang{180}\) phase inversion of the signal, which also allows direct comparison with the theoretical gain.  

\begin{equation}
    \label{eq:AVdef}
    \Ax{V} = - \frac{\Vx{o}}{\Vx{sig}}
\end{equation}



The calculated and measured values are summarised in Table~\ref{tab:p2gain}.  
The relative difference in \(\Ax{V}\) was calculated using Equation~\ref{eq:diff}.

\subsection{Input Impedance}
% #region

The input impedance of the amplifier can be estimated theoretically using Equation~\ref{eq:Zicalc}, which is referred to as Eq.~3.3 in the assignment.  
The data sheet specifies a transistor current gain in the range 150--400.  
An approximate value of \(\beta = 250\) was chosen for this calculation.  

\begin{equation}
    \label{eq:Zicalc}
    \Zx{i} = R_1 \parallel R_2 \parallel (\beta \cdot \rx{e})
\end{equation}

The input impedance was also determined experimentally by inserting a series resistor of \(\qty{1}{\kilo\ohm}\) at the input and setting the signal generator to \(\qty{20}{\milli\volt}\).  
From the resulting division of voltage between \(\Zx{i}\) and \(\Rx{x}\), the input impedance is obtained according to Equation~\ref{eq:Zimeas}.  

\begin{equation}
    \label{eq:Zimeas}
    \Zx{i} = \frac{\Vx{o}}{\Vx{sig} - \Vx{o}} \cdot \Rx{x}
\end{equation}

The results of the theoretical and experimental calculations are summarised in Table~\ref{tab:p3Zi}.  
The relative difference in \(\Zx{i}\) was calculated using Equation~\ref{eq:diff}.

\subsection{Output Impedance}
% #region

The output impedance is first estimated theoretically using Equation~\ref{eq:Zocalc}, which corresponds to Eq.~3.4 in the assignment.  

\begin{equation}
    \label{eq:Zocalc}
    \Zx{o} = \Rx{C}
\end{equation}

The experimental value of \(\Zx{o}\) was obtained by loading the output with a resistor and using the voltage-divider relationship between \(\Zx{o}\) and \(\Rx{L}\).  
Following the same approach as for \(\Zx{i}\), the expression in Equation~\ref{eq:Zomeas} is derived from the divider that produces the loaded output \(\Vx{L}\) from the unloaded \(\Vx{o}\).  

\begin{equation}
    \label{eq:Zomeas}
    \Zx{o} = \frac{\Vx{o} - \Vx{L}}{\Vx{L}} \cdot \Rx{L}
\end{equation}

The signal generator was set to \(\qty{14}{\milli\volt}\) to avoid distortion, with a load of \(\Rx{L} = \qty{3}{\kilo\ohm}\) connected.

\subsection{Power and Efficiency}

The DC input power is obtained from Equation~\ref{eq:PiDC}, which is Eq.~3.5 in the assignment.  
Since \(\Ix{C} \approx \Ix{E}\), the collector current is used.  

\begin{equation}
    \label{eq:PiDC}
    \Px{i} \text{ (DC)} = \Vx{CC} \cdot \Ix{C}
\end{equation}

The maximum theoretical output swing is determined by the supply voltage \(\Vx{CC}\) and the DC bias at the collector.  
In this case, the maximum peak-to-peak output is approximated as %\(\Vx{o} = 2 \cdot \Vx{C}\).  
From this, the maximum AC output power is estimated using Equation~\ref{eq:PoPP}, corresponding to Eq.~3.6 in the assignment.  

\begin{equation}
    \label{eq:PoPP}
%    \Px{o} = \frac{(\Vx{o}^{p-p})^2}{8 \cdot \Rx{C}}
\end{equation}

The efficiency is then calculated using Equation~\ref{eq:eta}, which is Eq.~3.7 in the assignment.  

\begin{equation}
    \label{eq:eta}
    \eta = \frac{\Px{o}}{\Px{i}} \cdot 100
\end{equation}
